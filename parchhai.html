Fact Retrieval Before Generation

Before executing any prompt, `VerifiedEvidenceExtractor` queries real Wikipedia articles and digitized district gazetteers within a 2.5km radius of the pin.

🛑

Hard Threshold Gatekeeper

If fewer than 3 verified evidence items exist, Parchhai refuses to call the LLM, presenting an honest notice rather than fabricating fake history.

🔒

Temperature Locked to 0.3

Locked to 0.3 to enforce maximum fidelity to source facts while weaving atmospheric prose, mandating that every story cite its specific evidence block [E1], [E2].

🛡️

Pre-Render Automated Audit

`StoryEvidenceAuditor` cross-checks citations against claims and geographic coordinates, dropping or downgrading any unverified hallucination before it touches the screen.

Cartography & Performance

OSMDroid Cartography & Optimizations

Open-source OpenStreetMap integration with zero API costs and custom single-pointer overlay.

Optimization Pass Technical Implementation Impact
Single-Pointer Overlay `map.overlays.removeAll { it is Marker && it !== marker }` Eliminates duplicate marker bugs during rapid pin dragging or GPS updates.
Tile Cache Throttling Threads throttled to 2, in-memory tile cache capped at 32 Prevents out-of-memory (OOM) crashes and eliminates battery drain on older devices.
Spatial Caching `lat_XX.XXX_lng_YY.YYY` (~110-meter precision keys in Room) Prevents redundant network calls when users inspect the same street block.
Connection Pool Consolidated singleton OkHttpClient with HTTP/2 multiplexing Reduces network handshake latency by ~65% across REST requests.
